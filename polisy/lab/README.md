# POLISY lab

Research theme 1: Political Ideology × AI × Innovation. The lab links VRscores workforce partisanship to AI exposure
(AIOE, DAIOE), migration (IRS SOI), state politics and policy (CSPP), and, when present, AI adoption (Census BTOS) and
AI patents (PatentsView). It keeps every pattern it finds as a graded finding and writes an interactive website.

- `polisy_lab/`: the package. `sources.py` (dataset registry, file discovery inside folders and zips, downloads,
  profiles), `adapters/` (one per source, writing canonical Parquet tables), `link.py` (panels and match rates),
  `analyses/` (findings, charts and tables), `site.py` and `site_assets/` (the website), `run.py` (`run_all`).
- `notebooks/POLISY_AI_Innovation_Lab.ipynb`: runs everything in Google Colab; `polisy_lab_colab.py` is the same code
  as a script. Both are generated by `tools/make_notebook.py`.
- `docs/TECHNICAL_REPORT.md`: how to run it, what each stage does, the datasets and how they link, the methods, what
  the first run found, and how to extend it. The site's Methods tab shows the same text.
- `tests/test_lab.py`: tests on real files only (each skips when its dataset is not found):
  `POLISY_TEST_DATA=/path/to/downloads POLISY_TEST_FULL=1 python -m pytest tests -q`.
- `tools/`: rebuild the map shapes (`make_us_states.py`, `make_us_county_points.py`) and the notebook.

Quick start outside Colab:

```python
import os, sys
os.environ["POLISY_LAB_ROOT"] = "/path/to/POLISY/lab"          # where the lab writes
sys.path[:0] = ["polisy/POLISY_DA", "polisy/lab"]
import polisy_core as pc
from polisy_lab import run_all
pc.CONFIG["SEARCH_DIRS"] = ["/path/to/your/downloads"]
run_all()                                                     # fetch, inventory, profile, adapt, link, analyze, site
```
